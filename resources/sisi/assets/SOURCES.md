# 标识来源

- 原始文件：`sisi-official.svg`，来自 [上海创芯学院官网](https://www.sisi.edu.cn/main.htm)。
- 原始地址：<https://www.sisi.edu.cn/_upload/tpl/02/4b/587/template587/images/logo.svg>
- 获取日期：2026-10-10。
- `sisi-name.svg`、`sisi-symbol.svg` 沿用原 SVG 的路径，仅通过 viewBox 分别显示校名和图形。原始文件保留不变。
